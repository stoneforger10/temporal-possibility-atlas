# Boundary and proof obligations

Caller action → pinned source identity + interval names → validator-side complete fetch → independent pair interpretation → exact normalized report agreement → deterministic complete endpoint-model envelope → immutable root-bound temporal query.

The contract owns evidence acquisition, normalized report validation, consensus comparison, exact model enumeration and immutable publication. A UI may preview/index but cannot supply a decisive vector. The external publisher owns authored text, not authoritative measurements. No settlement or real-world certificate exists.

## Completeness of the exact solver

Each proper interval has two labeled endpoints with start < end. Any finite collection of endpoints has an ordered partition into equality blocks. Replace each block by its zero-based rank; all strictly monotone time transformations yield the same canonical ranks. Inserting the next labeled endpoint into an existing rank or between ranks generates each ordered partition once: removing that label recovers its unique parent. The prefix start/end check discards only orders already impossible. This enumerates all 13 two-interval and 409 three-interval worlds, including touching endpoints; permutations alone would miss equality.

Every world is tested against every interpreted pair restriction. The envelope is the projection of this complete filtered set onto each pair, with a canonical first witness and digest of the lexicographically sorted worlds. A singleton relation means universal entailment conditional on the interpreted document. Any projected relation has a world witness. An absent one has no world witness under exhaustive bounded enumeration. An empty world set does NOT imply every relation: queries return NO_CLAIM.

## Consequential nondeterminism

The AI must translate natural-language distinctions into restrictions: strict gap versus touching, containment versus overlap, negation, reversed phrasing and underspecified endpoint inequalities. These are not computed from stored graph labels or hashes. Replacing a valid BEFORE with AFTER can change the admissible worlds, inferred relations and consistency outcome. Callback tests actually invoke a validator with a well-shaped but substantively wrong report and verify rejection after a new fetch and model call.

The model is not trusted to run the solver or invent one favored ordering. Constraints are normalized before consensus; a missing pair keeps all thirteen possibilities. Validators independently see the complete source and requested pairs, not a leader summary. All decision-bearing fields must match exactly; there is no confidence score or threshold tolerance. The full interpretation is bound to source bytes, policy, event names and contract. Deterministic state writes occur only after consensus and another context-integrity check.

## Lifecycle

There is one write, analyze. Its terminal immutable result is HELD, INCONSISTENT, DETERMINED or AMBIGUOUS. These are not graph transitions or certificates; no later consume/finalize/approve method exists. Every query binds the entire record root. Reads cannot alter the record. A differently named principal cannot replace an existing content-addressed analysis.

## Reviewer question

Could this only verify caller-supplied information? It does not accept a caller's interpretation, support vector, summary or ordering as evidence. Each node fetches the source independently. However, a caller can publish the source itself; therefore the contract intentionally makes only a conditional statement about that authored document. It does not claim source independence, factual event occurrence, service delivery or agent alignment. Source hashes are integrity checks, never semantic proof.
